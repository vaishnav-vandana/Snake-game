## 🚀 About the Project

This is a simple **Snake Game** developed using **Python** and the **Pygame** library.

The project was created as part of my Python learning journey to understand game development concepts and improve my programming and problem-solving skills.

The game allows the player to control a snake, collect food, increase the score, and try to achieve the highest score.

---

## 🎮 Features

* 🐍 Snake movement
* 🍎 Food generation
* 📈 Score tracking
* 🏆 High score saving
* 💥 Game over screen
* 🔄 Restart option
